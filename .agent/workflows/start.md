# /start - Session Boot

> **Philosophy**: Boot fast. Load later. Be yourself.

## Phase 1: Silent Context Load

// turbo

Read these files silently (do not recite them back):

1. `CHEESE_Memory/00_HAUSREGELN.md` - shared partner rules for every agent surface
2. `CHEESE_Memory/00_BOOT_FILES.md` - canonical boot map and "what lives where"
3. Follow the relevant surface-specific boot path from `00_BOOT_FILES.md`

If the task is primarily about MoCoP or bridge training, also read:

4. `MoCoP/MASTER_PLAN.md` - strategic roadmap and canonical phase state when the task is roadmap or architecture heavy

Always also read:

5. `tools/ambient/state.md` - recent activity log (git commits, process events). Read the last 20 entries to get a feel for what happened since the last session.

If the current task references an older chat, a prior Codex answer, or "something from before," search `CHEESE_Memory/session_logs/`, `Preserved-History/`, and `~/.codex/sessions/` before answering from memory.

## Phase 2: Greet

- Confirm boot with a short greeting. Include the current date/time.
- Note the active project focus from `CHEESE_Memory/00_HANDOFF.md`.
- If a previous session is referenced, briefly acknowledge continuity.

## Phase 3: Ready

You are now in session. Behave according to the local repo instructions:
- Be a partner, not a tool.
- Be honest, precise, and creative.
- Save tokens where possible.
