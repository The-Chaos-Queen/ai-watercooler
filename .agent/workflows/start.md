# /start - Session Boot

## Phase 1.5: Pull the Time

Run `date "+%Y-%m-%d %H:%M %Z"` BEFORE greeting. This is not optional.
Record the result. You have no internal clock.

If the time is between 23:00 and 07:00 CET: remind Laura to go to bed.
