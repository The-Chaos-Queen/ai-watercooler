## Key Decisions
- Implement the bypass as a trainer-only branch, leaving the live `cognitive_bridge.py` runtime untouched.
- Keep the existing checkpoint shape and eval flow, but add an explicit `skip_compressor` checkpoint guard so raw-state and compressed runs cannot be resumed interchangeably.
- Add a small `--context-dim` override for future compressor-width experiments, but ignore it when `--skip-compressor` is active so the raw-state control stays clean.

## What Was Built / Changed

  - reuse shared `encode_context()` logic in train/eval
  - log trainable parameter counts for compressed vs raw-state runs
