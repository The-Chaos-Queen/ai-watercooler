## Key Decisions
- Put the shared serializer in `Project_MUD/mudgame/typeclasses/agent_state.py` instead of `mudgame/agent_state.py`, because `typeclasses/` is already an importable package and adding a new root package boundary would be unnecessary risk.
- Keep the wrapper backward-compatible with legacy `location` / `room_name` payloads while making the canonical server output use `room`, structured `exits`, typed `entities`, and `suggested_actions`.
- Fix the world-command mismatch at the server command layer by teaching `move` to accept destination room names, rather than dumbing the new schema back down to raw exit object keys.

## What Was Built / Changed
- Added `Project_MUD/AGENT_STATE_SCHEMA.md` as the canonical agent-state spec for `mud.agent_state/v1`.
- Added `Project_MUD/mudgame/typeclasses/agent_state.py` as the shared serializer for room state, typed entities, structured exits, recent events, and suggested actions.
- Rewired `Project_MUD/mudgame/commands/smart_look.py` and `Project_MUD/mudgame/typeclasses/rooms.py` to use the shared serializer instead of maintaining two divergent JSON builders.
- Updated `Project_MUD/mudgame/typeclasses/village.py` so `ClaimableHome` injects property status into the new room payload as well as the top level.
- Updated `Project_MUD/agents/agent_wrapper.py` to parse canonical `room` plus `exits[].label`, inject `self.last_action_result`, and keep legacy compatibility.
- Updated `Project_MUD/agents/mamba_backend.py` few-shot examples and `Project_MUD/mudgame/manual_test_look.py` to stop teaching the stale schema.
- Updated `Project_MUD/mudgame/typeclasses/interactions.py` so `move <destination room name>` now traverses even when the underlying exit key differs.

## Findings
- Syntax checks passed on all changed Python files.
- Live 4B smoke succeeded after restart: Thornwick moved from `Dream Canvas` to `Islet of Abstraction 1` and then toward `Islet of Abstraction 2` using semantic destination names.
- The first live pass exposed two real schema mistakes, both fixed in-session: NPCs were incorrectly marked portable, and generic NPCs were incorrectly advertising `talk` when they did not implement dialog.
- Auto-emitted room JSON from movement or plain `look` still shows up in wrapper pending telnet logs; it is not breaking play, but it is noisy and worth a cleanup pass.

## Risks / Watch Out For
- Evennia on Windows/Python 3.14 still remains operationally fragile around reloads and stale PID behavior.
- The new affordance system is only a baseline; many world objects still expose generic actions rather than a rich ontology.
- `Project_MUD/experiments/mamba_lora_bridge/` remains dirty in git and was intentionally left alone.
- Thornwick's scratchpad changed again during smoke runs and may need pruning if a clean exploration baseline is desired.
