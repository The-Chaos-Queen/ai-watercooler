- But the new failure is now sharper:
  - `Who am I to you?` -> plausible but generic hallucination (`special friend`)
  - `Do you recall what happened yesterday when I asked your name?` -> wrong recalled theme (`we don't use a specific prompt`)
  - `Can you summarize what you remember from earlier?` -> coherent but fabricated summary built from the wrong retrieved memories
  - `VW Passat` -> recall still missed the best actual match until Laura reminded it manually
- The retrieval diagnosis is now explicit:
  - the relevant fresh turns exist in `qdrant_gate_pending.jsonl`
  - the auto-recall path only searches stored Qdrant points
  - therefore stale stored prompt-confusion rows outrank the fresher, actually relevant pending rows

## Risks / Watch Out For
