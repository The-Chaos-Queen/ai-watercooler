# Session Log: 2026-02-20 (Session 01)

## Summary
The session focused on migrating Mamba-2.8B inference to WSL2 on the Opa-PC to resolve performance bottlenecks and addressing Jinx's repetitive behavioral loops. We successfully prepared the WSL environment and BIOS, though CUDA compilation remains pending a toolkit installation.

## Key Decisions
- **WSL over Windows Native**: Abandoned native Windows compilation for Mamba's CUDA kernels due to persistent build errors.
- **Systemic Memory injection**: Chose to inject a `"memory"` flag into the agent's prompt based on scratchpad history rather than modifying the MUD's core state model, allowing for a faster iteration on behavioral fixes.

## Learnings
