## Findings
- Existing logs showed the exact failure mode: chatter plus a full tagged room payload in the same `MUD Log`, which polluted recent context.
- The patched sanitizer preserves nearby speech/system text and reduces the room blob to a compact summary with room name, exits, and up to three visible entities.
- Focused unittests pass locally.

## Risks / Watch Out For
- The filter only collapses JSON that parses cleanly and looks like room state or an error payload. Severely malformed partial JSON can still survive as plain text noise.
- Older wrapper logs still contain raw JSON clutter from previous runs, so only new traces should be used to judge current behavior.
