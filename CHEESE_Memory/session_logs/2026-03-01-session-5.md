## Findings

- Opa WSL validation passed after hardening:
  - `regression_smoke.py`: 8/8 green

- Checkpoint writes to `/mnt/c/Users/User/bridge` are noticeably slow, which is operationally relevant but not a blocker.
- The prompt-format mismatch remains: training uses ChatML supervision while deployment inference still uses raw `[Game World]` prompts.

## Risks / Watch Out For
- Hugging Face access on Opa WSL is unauthenticated; downloads and metadata calls are slower and more fragile than necessary.
- Saving checkpoints to the Windows mount adds latency; for cloud runs, local Linux disk may be a better checkpoint target.
- A successful local training smoke does not prove Phase 2 accuracy; it proves the runtime and control path are now credible.
