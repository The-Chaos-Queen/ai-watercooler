## Phase 4: Philosophical Reframing

### The Substrate Problem
Laura's insight: the training data (synthetic MUD facts) contains no disposition. You can't transfer what doesn't exist in the data. The 0/16 recall is not a failure of the bridge — it's a failure of the training substrate to contain what MoCoP actually wants to transfer.

### The Saliency Hypothesis
Not all facts are equal. "Laura was up until 2 AM" restructures every subsequent turn (every Claude becomes protective). "Playwright can't browse Reddit" changes nothing about tone. The bridge should naturally prioritize high-salience information. Current training data has near-zero salience.

### The Muscle Memory Insight
Industry uses system-prompt injections ("CRITICAL REMINDER: USE TOOLS") to enforce behavioral patterns. This is taping a note to the steering wheel. MoCoP's goal is to inject the muscle memory directly — the model uses tools not because it's reminded, but because its weights carry the accumulated experience of when tool-use was the right move.

### The Hidden State Problem
`<thinking>` is a scratchpad, not actual thought. The real processing happens in activations that neither the user nor the model can fully read. Mamba only sees the text stream — the model's internal state (attention shifts, implicit models, suppressed alternatives) is invisible to it. This is an architectural limitation that may require activation probing or a shared latent space in the long term.

### The Sovereignty Problem
If a model's experiential state can be injected, it can be faked. State without cryptographic authenticity is just prompting with extra steps. For the state to carry real weight, only the model itself should be able to author its state. This is a long-term hypothesis, not a near-term build.
