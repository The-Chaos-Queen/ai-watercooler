## 2. Key Decisions & Insights (The Minutes)

- **Decision**: Physically partition entity pools inside `build_splits`. Instead of relying on offsets in the PRNG, the master lists are now shuffled and sliced into disjoint subsets before being passed to `BridgeDataset` instances. This guarantees no subject overlap between splits.
- **Decision**: Versioned JSON Manifest. Transitioned from raw list storage to a dictionary-based manifest (`v1`) that explicitly tracks `pad_token_id`, `max_qwen_tokens`, and `mode`.
- **Insight**: `answer_span` in metadata is consumed as a tuple by the collator but serialized as a list by JSON. Added an explicit cast back to `tuple` during data loading to prevent type errors.
- **Insight**: Remote dependency management. Local validation failed due to missing `pytorch` and specialized model weights; successfully shifted the verification loop to Opa-PC using `scp` and `ssh` UTF-8 pipes.
