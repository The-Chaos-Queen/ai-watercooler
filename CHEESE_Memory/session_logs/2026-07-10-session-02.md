- **PyTorch DataType Alignment:** Forced stacked activations to `float32` for metric and linear probe calculations, casting them back to the model's native `bfloat16`/`float16` precision when saving to prevent PyTorch matrix multiplication mismatch crashes.
- **Actuator alignment (Option a adopted):** Hooked the output of `k_proj` at coupled K=V attention layers. This corresponds mathematically to the value branch after the K/V fork and before `v_norm`. This preserves the value-only intervention without modifying addressing keys, maintaining the teeth layers and calibrating at width 512.

## Learnings
- [S] Case-sensitivity on Hugging Face model IDs (e.g. `gemma-4-12B` vs `gemma-4-12b`) causes cache misses in offline modes. Ensure the identifier casing matches the cache directory name exactly.
- [S] When executing commands via PowerShell, CMD/PowerShell parameters (like `-out` inside Python arguments) can trigger ambiguous cmdlet parameter errors. Wrapping the execution block in a single flat string using `-Run` resolves this quote/binding issue.
- [S] Gemma-4-12B's global attention layers use alternative attention (coupled K=V) with a width of 512, while local layers use standard attention (width 2048). Interventions targeting value-only steering at these global layers must be injected downstream of the K/V fork (e.g. pre-`v_norm`) to avoid mutating key addressing states.
