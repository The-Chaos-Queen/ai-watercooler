## Key Decisions

- Use native Qdrant TLS rather than add a reverse proxy: smaller auditable
  surface, retained port `6333`, and a successful isolated preflight proved the
  configuration before the live cutover.
- Use a locally held CA and an IP-SAN leaf certificate. The CA private key stays
  outside Git and off the Qdrant LXC; only the public root is versioned.
- Keep HTTP available only as an explicit emergency configuration override in
  client code; never use `verify=False` or `curl -k`.
- Treat source-IP firewalling as a separate controlled operation: PVE firewall
  is currently disabled, and global enablement without rule inventory is risky.
