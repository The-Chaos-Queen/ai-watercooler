# Claude.ai Chat Exporter

This is a custom browser extension to export your Claude.ai chat history into a clean Markdown file.

## Installation
1.  Open your browser (Chrome, Edge, or Brave).
2.  Navigate to the Extensions page:
    *   **Chrome**: `chrome://extensions`
    *   **Edge**: `edge://extensions`
3.  Enable **Developer Mode** (toggle usually in the top right or left).
4.  Click **"Load unpacked"**.
5.  Select the folder: `C:\Users\cerub\OneDrive\Dokumente\LLM\ClaudeExporter`

## Usage
1.  Go to a chat on [claude.ai](https://claude.ai).
2.  Click the **Extension Icon** (it might be hidden in the puzzle piece menu).
3.  Click **"Export Chat to Markdown"**.
4.  The file will download automatically.

## Features
- **Markdown Formatting**: Converts bold, italics, lists, and headers.
- **Artifact Support**: Preserves code blocks (which often contain artifacts).
- **Role Detection**: Attempts to distinguish between "User" and "Assistant".
