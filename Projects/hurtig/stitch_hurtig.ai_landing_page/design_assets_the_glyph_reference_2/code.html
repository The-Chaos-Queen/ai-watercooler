Browser Fallback & Webfont Strategy

Because the Sumerian cuneiform 'ul' (𒄉) sits outside the standard Unicode BMP (Basic Multilingual Plane), it is missing from 99.9% of system fonts. To guarantee visual continuity, we employ a tiered rendering architecture.

We utilize a subsetted 'Noto Sans Cuneiform' woff2 file containing only the required glyphs, reducing the payload from megabytes to just 4KB.
