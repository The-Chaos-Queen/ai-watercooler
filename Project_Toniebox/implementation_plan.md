# Implementation Plan - Toniebox Hack & TeddyCloud Setup

**Goal**: Host a custom Toniebox server (TeddyCloud) on Proxmox and configure a 2018/2019 Toniebox (CC3200) to use it.

## User Review Required
> [!IMPORTANT]
> **Port 443 Usage**: TeddyCloud **MUST** own port 80 and 443 on the IP address it runs on. If your Proxmox Docker host already uses port 443 for something else (like Nginx Proxy Manager), you will need to give TeddyCloud a dedicated IP (e.g., using `macvlan` in Docker or a separate LXC/VM).

> [!WARNING]
> **Warranty Void**: Opening the Toniebox and flashing custom firmware/certs voids the warranty. Since you've already replaced the battery/ears, this is likely fine.

## Proposed Changes

### 1. Server Setup (TeddyCloud)
We will deploy TeddyCloud using Docker.
- **File**: `docker-compose.yaml`
- **Action**: Create this file on your Proxmox server.
- **Configuration**:
    - Generates necessary certificates on first run.
    - Exposes Web UI on port 80 (or 8080 if mapped) and 443 for the box.

### 2. DNS Configuration
For the Toniebox to find your server without hardware modification (initially) or after modification, we usually need DNS entries.
- **Task**: You will need to configure your home router (or Pi-hole/AdGuard) to redirect `prod.revvox.de` and `rtnl.tonies.com` to your TeddyCloud server IP.
- *Note*: The "Hack" (replacing the CA) allows the box to trust your server, but DNS is still needed to route the traffic unless we patch the firmware IP (which is more advanced).

### 3. Hardware Hack (CC3200)
- **Requirement**: USB-to-Serial Adapter (3.3V logic).
- **Process**:
    1.  Open Box.
    2.  Connect RX/TX/GND.
    3.  Dump existing flash (Backup!).
    4.  Flash `ca.der` (generated by TeddyCloud) to `/cert/c2.der`.
    5.  (Optional but recommended) Flash **HackieboxNG** bootloader for dual-boot/safety.

## Verification Plan

### Automated/Manual Tests
1.  **Server Verify**: Access TeddyCloud Web UI at `http://<server-ip>/`.
2.  **Certificate Check**: Download `ca.der` from the Web UI/file system.
3.  **Flash Verify**: After flashing, Toniebox should turn green when placed on the charger (connecting to wifi and your server).
4.  **Content Test**: Place a custom file on the server and play it on the box.
